**Proposal only:** no permanent ticket id or tracker status. Parent: T-0016 / P13 prerequisite supplement. **Blocked by:** none; uses the already landed T-0016 baseline, not its completion.

## Context

Both native policy and preparation currently refuse every workflow path; adding an exact engineering-map digest cannot make a future trusted validation workflow usable. Default denial and historical validators must survive.

## Deliverable

A maintainer can supply an independently approved finite workflow identity to a public local preparation and obtain matching main/staging engineering projections. Without approval, or with one identity changed, the same public flow refuses. The demo uses disposable Git; real workflow installation/activation is outside the ticket.
