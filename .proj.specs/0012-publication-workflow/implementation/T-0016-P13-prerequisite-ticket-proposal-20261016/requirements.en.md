An input owned by another UID (including root when the job UID differs) is refused. A trusted preflight may copy independently digest-verified source bytes into this snapshot before sealing it; the same predicates apply before consumption. Open without following symlinks, compare opened identity with the checked path, and reject changed device/inode/size/mtime/ctime or digest during the read; consume only the checked in-memory bytes.
