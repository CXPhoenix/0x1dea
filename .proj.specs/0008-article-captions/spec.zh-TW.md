# 文章圖說、表題與引用自動編號

英文規格 v2 為準；此份供使用者核對。2026-10-11 確認方向，僅限本機交付。

## 問題與解法

目前作者須手動維護圖說及每一處圖號；meme 不應編號，表格也需要同樣能力，且 caption 與 alt 必須分開。

以明確標記的 Markdown 區塊，在建置時產生語意正確的圖說、表題及當篇編號；正文以固定名稱引用，支援先引用再定義。先轉換用電文章的三張知識圖，保留另外五張圖片（含橫幅）、所有原始 alt、圖片檔案、frontmatter 與其他內文。

## 使用情境與實作決策

1. 作者只寫一次 caption，網站自動產生號碼。
2. 作者引用固定名稱，插圖或換序後所有引用一起更新。
3. 讀者可以沿圖表引用跳轉，圖片仍有替代文字。

- 擴充既有 VitePress Markdown 設定，不新增依賴、不用瀏覽器計數器。SSR 即含完整號碼，換頁後一致。
- `::: figure 名稱` 內放一張獨立 Markdown 圖片，以非空白 title 為 caption，alt 保持獨立。`::: table 名稱 表題` 內放一張 Markdown 表格。最後以獨立一行 `:::` 結束，不允許巢狀編號區塊。名稱符合 `[a-z][a-z0-9-]*`；無效區塊轉換失敗。
- 圖片、表格各自從 1 開始，依當篇出現順序計號。一般圖片、原始 HTML 圖片及一般表格維持原本行為，其他文章不需搬移。
- 圖片產生 `<figure id="fig-名稱">` 與下方 `<figcaption>`；表格使用真正的 `<caption>` 作為第一個子元素，表格 ID 為 `tbl-名稱`。標籤為「圖 N：」「表 N：」。Caption 支援純文字、強調、一般 Markdown 連結及原文來源連結；HTML、Vue 插值顯示為文字，連結沿用既有 URL 檢查。
- 正文 `@fig:名稱`、`@tbl:名稱` 產生同頁原生連結，支援前後引用與 `<small>` 圖源註記，不吞掉相鄰中文字。程式碼、跳脫標記、圖片 alt/title、HTML 屬性、既有連結文字與網址不轉換；caption 內也不解析引用。
- 同種類名稱重複、引用不存在／種類不符、名稱無效、缺 caption、缺結尾、內容無效或 anchor 撞名時，診斷須包含相關名稱／區塊／引用。圖與表可共用名稱，因 namespace 不同。保留 `fig-`／`tbl-` namespace，檢查與靜態 HTML／產生的標題 ID 碰撞；動態 Vue ID 不在範圍內，作者也不得使用保留 namespace。
- 文章所有手寫圖號（含圖源註記）改為固定引用，保留來源敘述與引用連結、原始 alt/src、frontmatter 時間及既有較短的第一張圖說。文章沒有表格，表格由範例驗證，不新增內容。
- 樣式限於標記的圖表，提供響應式呈現與可見鍵盤焦點，並提供作者語法與錯誤說明。

## 驗收條件

| 編號 | 可觀察結果 |
|---|---|
| C1 | 兩張知識圖分別顯示圖 1／圖 2，語意正確且 alt/caption 獨立；中間 meme／原始圖片不編號 |
| C2 | 兩張表格各有原生 caption 表 1／表 2，一般表格不編號，圖號不影響表號 |
| C3 | 前後引用連到正確目標，含 `<small>`；插入／換序後更新；同一 renderer 換文章重新計號 |
| C4 | 指定不轉換的情境保持文字，中文與標點不變；caption 連結／強調正常，HTML／Vue 為文字，不產生可執行的不安全網址 |
| C5 | 所有指定錯誤產生診斷；非 opt-in 一般 Markdown 照常呈現 |
| C6 | 用電文章恰有三張編號知識圖、六處自動引用，保留八組原始圖片 alt/src，無手寫圖號，其他 bytes 可還原為進場快照 |
| C7 | 實際瀏覽器 1280px／390px、淺色／深色驗證：caption 字級至少 14px、文字對比至少 4.5:1、文字無裁切、頁面無 overflow；引用可鍵盤聚焦且有 outline，啟用後 hash 正確；SSR 與站內換頁一致 |
| C8 | 使用既有工具執行 unit／lint／build／結構／materializer／adoption 檢查，區分既有問題與回歸；不 commit／push／deploy／安裝／改歷史 guard |
| C9 | 指南提供可複製的圖／meme／表／一般表／引用／來源範例、alt 說明、每篇計號與錯誤診斷；範例經同一 renderer 驗證 |

## 測試決策與排除範圍

使用既有 Markdown renderer 的 HTML／錯誤輸出、進場文章保存比對及實際瀏覽器介面驗證，不測 plugin 私有實作。單一 ticket 與測試表已由使用者核准；四個獨立規格審查面向在第二輪通過。

不批次轉換其他文章、不生成圖說、不判斷 meme、不做跨文章引用或圖表目錄、不轉換 raw HTML 圖表、不支援巢狀編號區塊、不修改寫作技能套件。發佈與 landing 需另行授權。
