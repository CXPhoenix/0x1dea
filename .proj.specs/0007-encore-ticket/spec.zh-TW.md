# 可重複使用的同場加映票券

## 問題與解法

用電與隱私文章目前以一般段落呈現延伸閱讀。使用者選擇 D「加映票券」，希望將它做成可重複使用的 Vue 元件，並套用到原本的位置。

`EncoreTicket` 全域註冊到 VitePress，可直接在 Markdown 使用。只替換現有推薦段落，保留文案、目的地、前後文、frontmatter、圖片與本次開始前已有的圖說修改。

## 使用情境

1. 讀者可以從具有辨識度的票券開啟推薦文章。
2. 作者提供標題、連結及選填的說明文字，即可重複使用票券。

## 實作決定

- 公開 props 為必填的 `title`、`href`，及選填的 `description`。文字透過 Vue interpolation 顯示；不解析 HTML、不使用 slot、不查詢遠端資料，也不新增套件。
- 保留 D 的直排「同場加映」票根、ENCORE、虛線、上下缺口、「延伸閱讀」標籤、標題、說明與「來看這一篇」入口。
- 整張票券是一個原生連結，沒有巢狀按鈕或連結，在同一分頁開啟作者提供的原始 `href`。
- props 來自可信任的文章作者；這不是供不可信任遠端網址使用的過濾器。
- 使用 CSS module 與網站既有色彩變數，支援深淺色。ENCORE、箭頭與缺口是裝飾，不加入連結的可存取名稱；鍵盤焦點須清楚可見且不被裁切。
- 手機保留較窄的直排票根，文字可換行、不固定高度。省略說明時不產生空白段落。
- 僅新增這篇文章作為正式使用處，並提供包含有／無說明文字的使用指南。

## 驗收條件

- **E1**：兩個實例可獨立顯示不同的原始標題、連結與說明，HTML 形式的文字不會變成 HTML。省略說明時不留下該段落，標題、入口與原連結仍保留。指南包含兩種 props 用法。
- **E2**：實際編譯後的文章在原推薦位置顯示一張已註冊票券，文案與目的地保持相同，下一個章節仍在元件外。
- **E3**：在 1280px 與 390px 的真實瀏覽器、深淺色主題下，具有核准的 D 結構，不超出文章寬度、沒有裁切或水平溢出。省略說明的行為依 E1 的明確斷言驗證。
- **E4**：Tab 可聚焦並顯示焦點外框；可存取樹呈現包含推薦標題的單一連結，不朗讀 ENCORE 與箭頭。啟動連結後在同一分頁開啟原推薦文章。
- **E5**：除了推薦段落替換，本次開始時的文章內容逐位元組相同。圖片、時間、其他文章、相依套件、歷史保存紀錄及 verifier 不變；其餘修改限於元件、註冊、指南、測試與追蹤證據。
- **E6**：unit、lint、VitePress build 及適用的結構／materializer 檢查通過。仍執行保存檢查，分別記錄既有圖說失敗及本次授權變更新增的 hash／來源清單拒絕，不宣稱該 verifier 通過、不修改歷史規則，改以嚴格獨立內容比對驗證 E5。本次不包含 commit、push 或部署。
