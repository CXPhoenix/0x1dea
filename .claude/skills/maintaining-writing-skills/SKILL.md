# 寫作與技能維護

依本次要改的內容讀所需資料：

- 技能／AGENTS／CLAUDE 指引修改：讀 [來源與設計選擇](../../../maintenance/writing-skills/SOURCES.md) 和 [技能維護](references/skill-maintenance.md)。
- 寫作專案脈絡、來源、文類結構或修訂／交付：讀 [寫作參考](references/writing-process.md)。
- 既有網站文章的 frontmatter、圖片、程式範例或完成檢查：讀 [文章維護](references/article-maintenance.md)。新文章骨架由 [creating-vitepress-post](../creating-vitepress-post/SKILL.md) 處理。
- 新規格、票與進度：讀 repo 的 [AGENTS.md](../../../AGENTS.md) 及 [本地追蹤設定](../../../docs/agents/issue-tracker.md)。openspec 與 [舊 Spectra 參考](references/spectra-codex.md) 只供唯讀追溯，不建立第二套任務流程。
- 使用舊 EAL+ validator 或追溯原始資料：讀 [舊規格相容](references/legacy-validator.md)。一般寫作不載入舊密度與固定序列。

修改前看 Git 狀態與目標檔案，保留同時修改。完成時交付具體變更、實際驗證與未解限制；修改範圍、寫入權限與外部動作依使用者授權。驗證失敗先判斷是否由本次變更引起，不順手修無關文章或網站缺陷。
