# 技能維護

有效內容放在 repo 的 skills；.agents/skills 與 .claude/skills 是完整實體套件。只改 canonical 來源，再執行 scripts/materialize-writing-skills.py --write；交付前用 --check 查漂移，不直接修改產物。風格定義在 phoenix-writing，CLI 契約在 creating-vitepress-post；只在對應來源修改一次。

description 說明真正觸發的任務，必要時列容易誤判的邊界。共通判斷留在 SKILL.md，只屬單一分支的詳細資料透過條件清楚的連結揭露。描述結果與必要不變條件，讓模型依脈絡選擇實現；每篇文章不跑相同模板或全套維護文件。

驗收對應行為：至少查驗適用案例、近似但不適用案例，以及明示要求與預設衝突的案例。新 script 必須實際執行；結構驗證只證明格式，不證明風格品質。記錄案例輸入、實際輸出與判斷，標清是否為本 agent 自檢、獨立測試或跨模型 eval。

改 agent 入口時，核對 symlink、相對連結、工作目錄假設及全域調用者。搬移先保存原始內容與 hash，再建立可恢復相容入口；碰到沒有權限的目標就停止該位置修改並揭露阻礙。

完成條件：本次修改的有效文件觸發精準、來源可追溯、引用／入口可解析，代表性案例符合結果；剩餘阻礙逐項明示。不以「已換成 GPT 字串」作驗收。
