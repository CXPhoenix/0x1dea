# 台灣用語校準

在台灣繁中作品使用讀者熟悉的詞。使用者指定其他語言、正式名稱、原文引用或程式識別字時，保留該要求。這是用詞參考，不是每個術語的強制中英縮寫模板。

| 意思 | 台灣用語 |
|---|---|
| software / hardware | 軟體／硬體 |
| program | 程式 |
| folder | 資料夾 |
| data / database | 資料／資料庫 |
| save / memory | 儲存／記憶體 |
| screen / mouse | 螢幕／滑鼠 |
| server / browser | 伺服器／瀏覽器 |
| video / print | 影片／列印 |
| internet | 網際網路 |

與讀者說話通常用「你」；正式稱呼依文類。全形中文標點搭配原文專有名詞，程式碼和精確字串保持原樣。例行轉折用合適的逗號、冒號或分句；破折號可保留真正的戲劇轉折，不按密度統計替換。

原版對照表及作者語料歸因見 [歷史用語](../../../../maintenance/writing-skills/legacy/phoenix-writing/reference/tw-vocabulary.md)。其中語氣頻率和不可覆寫的語言規定屬舊版，本檔是目前用詞判斷的來源。
