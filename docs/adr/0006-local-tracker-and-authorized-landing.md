# Use one local tracker and separate landing authority

The local English spec and single-file tickets are execution authority. Notion is an
external index managed by the parent. Imported Spectra history is read-only. Allocate
global sequential permanent ticket IDs by scanning all epics; derive blockers from
dependency edges. Pauses require reason, evidence, date and revisit condition.

The adoption ends at local review, not done. Only actual separately authorized landing
can produce done, with a real commit contained in the configured staging target and
an approval receipt. Product and template source repositories remain read-only.
CF production main is an independently configured external target and is unchanged.

For non-browser seams, owned Python subprocess harnesses execute the real Node helper,
fresh native app-server catalog and disposable recovery. They complement browser UI
inspection and independent writers/judges rather than replacing those surfaces.
