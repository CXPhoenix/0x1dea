# Generate complete physical product writing packages

Three writing skills retain one canonical editing source. Codex and Claude receive
deterministic physical files with their own metadata and correct local-link depth.
The generator pins every approved regular source and rejects unknown inputs, drift,
links and partial unsafe replacement. Framework packages retain pinned source bytes.

Only the two owner-approved canonical compatibility aliases remain symlinks. Their
literal targets and individual regular backing files are explicitly enumerated;
the materializer never follows them to discover inputs. Runtime trees contain none.
Staged installation preserves old targets on failure. `--check` recomputes expected
bytes in temporary storage without installing or silently repinning source hashes.
